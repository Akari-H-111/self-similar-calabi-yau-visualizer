What this page can—and cannot—claim

Deployment is version-specific. A public page proves only the commit currently deployed to GitHub Pages. Local source, an unmerged branch, and a historical release can each describe different capabilities.

The Simple view is a finite sampled two-parameter slice of X₀, followed by a declared 3D projection. Its bounded inverse-branch comparison is finite local numerical evidence. It is not a 3D embedding of the full real-six-dimensional object, a global self-similarity proof, or a metric-geometry zoom theorem.

Camera drag, wheel/pinch, and +/− change only the visual camera. A local comparison is generated only after a selected source point and a cap-checked, path-consistent branch request.

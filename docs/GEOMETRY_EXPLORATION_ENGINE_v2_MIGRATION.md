# Explorer v1 → v2 migration

- The v1 source contract and historical release documents remain unchanged. The current explorer contract is [v2 current state](GEOMETRY_EXPLORATION_ENGINE_v2_CURRENT_STATE.md).
- The top explorer's fixed structural `1,4,16` illustration was removed. The existing structural visualizer elsewhere on the page remains separate.
- A computed finite pullback mode now uses the canonical schema-v2 formula, seed sampler, point-fiber engine, ancestor scope runtime, and 10,000-point preflight cap.
- New controls select `D`, depth, finite seed versus one ancestor, and optional ancestor-centered display normalization. `λ` and `κ` still represent a real slice of the source complex family.
- The new parameter indicator evaluates the source discriminant criterion with exact decimal equality and an uncertainty state. It is not a new Lean theorem.
- Old `app.js` whole-file SHA-1 guards in the base renderer, Gate 2-D, and current-state provenance verifiers were replaced with semantic v1/v2 entrypoint checks. The immutable historical/formal blobs remain protected. The byte-pinned Thread 25 verifier remains an unchanged historical checkpoint; current CI runs the new geometry contract and Thread 28–31 successors instead. Gate 2-C/2-D execution-order assertions were retired because current CI explicitly treats them as historical checkpoint checks.
- Current verification is `node verify_geometry_exploration_contract_v2.js`, `node verify_geometry_exploration_engine_v1.js`, `node verify_geometry_exploration_engine_browser_v1.js`, the relevant existing geometry tests, and `cd formal && lake build`.
- The first-visit Simple mode now starts the same engine with a finite mesh of the declared two-parameter `X₀` slice, explicitly projected by `(Re z₁, Im z₁, Re z₄)`. The structural SVG playground and optional structural 3D descriptor camera moved to Expert mode.
- Selecting a mesh vertex now requests one cap-checked `9×9` local source patch and one named inverse root tuple. Raw projected panels and a separately labelled local-log normalization compare the 81 parent/child records. The comparison is finite numerical evidence, not a complete fibre, a fractal boundary, a metric theorem, or geometric zoom.
- The local patch is now center-anchored: the clicked source record cannot be replaced by a globally ordered quadratic-root label. A nearest-root continuation must agree on every already-reached path; a disagreement is an explicit zero-generation refusal. Simple mode also exposes the parameter classification and a first-viewport renderer failure message.
- The former Simple finite-fibre walk (`fixed_linear_real8_to_r3_v1`, 16/256/4096 descendants) remains an Expert finite-pullback capability; it is no longer presented as Simple mode's shape comparison.
